Sheet 8 · When a source changes shapeWhat catches it, and what fixes it

A 200 OK with an empty field is still a break.

Two things break a feed. The source stops answering, which every monitor catches, and the source keeps answering while a field quietly empties out, which most monitors do not. The second costs more, because the pipeline stays green and the data goes wrong for as long as nobody looks.

Shipping today · deterministic

The schema gate holds any batch where a field breaks its null-rate baseline. The gate runs on every field in the contract, on every source.

HOW THE GATE READS A FIELD · WORKED EXAMPLE

The schema gate

Every field carries a null-rate baseline, frozen from the batches before it. The gate reads each nightly batch against that baseline and holds the whole batch when a field falls outside. This is the break an HTTP check cannot see: the request returned 200, the row count was right, and realtoremail came back empty on every row.

32% → 100%Null rate on the field
HeldBatch does not ship
PagedA person picks it up

It catches the break. It does not write the fix.

Not shipping yet · the next layer

The gate already names the break and holds the batch. What we build next proposes the fix, and it has to clear the same gate before anything ships.

01
Detect

A gate trips: a field breaks its null-rate baseline, or propertyStatus returns a value outside the enum.

02
Diagnose

The failing page and the last-good extraction contract go to the model. It rewrites the parse path and leaves the pipeline alone.

03
Prove

Replayed against frozen golden fixtures and the same baselines. A fix that cannot reproduce the last-good output is rejected.

04
Promote

Only a proposal that passes ships, with the diff attached. Anything that fails pages a human.

The rule

The model never deploys anything it cannot prove against a fixture. Without that constraint the model is rewriting live parsers with nothing checking its work. It is why 70 spiders across 44 domains have not turned an overnight break into a morning call-out.

The bill is set by bytes on the wire.

About 45 KB of JSON on the wire, about 75 KB on the meter once TLS setup and retries are counted. Three of the six sit here.

Rung 2 · session minted once, then reused Compass · Homes.com 255 KB average $0.49per 1,000 requests

One 1.2 MB browser mint carries nine credentialed follow-ups near 150 KB, which averages to about 255 KB a request.

Rung 2 · every request scored Zillow 1,200 KB $2.29per 1,000 requests

A rendered page measured between 0.97 and 1.45 MB in our own captures. Zillow scores every request, so it never averages down.

Weight is charged per request and it does not amortise. Session reuse cuts the number of browser mints. Every request still pays its own bytes.
