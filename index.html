Buying reverses it

On the buy path you pay one vendor for access, and there is nowhere else to get it. Here the only single-sourced rows are the free ones, and being open source they cannot be withdrawn or repriced.

No single vendor

Every paid row has a named substitute at a comparable rate. Switching proxy vendor is a config change and a re-run on the same code.

The gap we close next: AI-assisted self-healing

The healing is deterministic today, and it works: the schema gate holds any batch where a field breaks its null-rate baseline. That is the 200 OK with an empty realtoremail that no HTTP check catches. It does not write the fix. The next layer writes it, under the same proof.

01Detect

A gate trips: a field breaks its null-rate baseline, or propertyStatus returns a value outside the enum.

02Diagnose

The failing page and the last-good extraction contract go to the model. It rewrites the parse path and leaves the pipeline alone.

03Prove

Replayed against frozen golden fixtures and the same baselines. A fix that cannot reproduce the last-good output is rejected.

04Promote

Only a proposal that passes ships, with the diff attached. Anything that fails pages a human, the same as it does today.

The rule

The model never deploys anything it cannot prove against a fixture. Without that constraint the model is rewriting live parsers with nothing checking its work. It is why 70 spiders across 44 domains have not turned an overnight break into a morning call-out.

Sheet 8 · What moves the billPick a tier mix

Page weight is the lever, not the browser.

A rung-1 JSON response is about 45 KB. A rendered rung-2 page measured between 0.97 and 1.45 MB in our own captures, roughly 25 times the traffic for the same listing. That weight is charged on every request and does not amortise, so moving a source down a tier saves more than any other change.
